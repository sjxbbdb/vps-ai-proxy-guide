# 采购指南

> 预算参考 **¥30–50/月**，付款方式：支付宝/银联。
> 目标：一台**美国原生 IP**、线路优化、能稳定访问海外大模型的 VPS。

---

## 一、先明确采购逻辑（比价格重要）

### 1.1 你的预算能买到什么

| 能力 | 能否做到 | 说明 |
|------|---------|------|
| 独享固定 IP | ✅ 能 | 这正是自建相对机场的核心价值 |
| 美国原生 IP | ✅ 能 | 选对商家即可（很多低价鸡是"广播 IP"） |
| 回国优化线路（CN2 GIA / CUII / CMIN2） | ✅ 部分能 | 年付 $42 档可拿到 CUII+CMIN2 |
| 真正的住宅 IP | ❌ 基本不能 | 通常 ¥34/月起且带宽小 |
| 免于一切风控 | ❌ **不能** | **自建 VPS 仍是机房 IP** |

> ### ⚠️ 必须纠正的误解
>
> 自建 VPS 的价值是 **独享 + 固定 + 少切换**，**不是**"变成住宅 IP"。
>
> 对 AI 工具而言，**"长期固定、来源清楚、少切换"比"住宅"标签更重要**。
> 把低价普通 VPS 当"高信任账号主力"，是被明确列为**不建议**的做法。

### 1.2 线路怎么选（按你的宽带运营商）

| 你的宽带 | 首选线路 | 说明 |
|---------|---------|------|
| 电信 | **CN2 GIA** | 全程 59.43.x.x 专用节点，避开拥堵 163 网 |
| 联通 | **AS9929 / CUII** | 联通自家高端线路，通常比 GIA 更便宜更好 |
| 移动 | **CMIN2 / AS58807** | 移动方向优化，晚高峰稳定性提升明显 |
| 不确定 | **CUII + CMIN2 双线** | 一档覆盖电信联通+移动，省心 |

**验证线路真伪**（商家宣传不可信）：

```bash
# 真 CN2 GIA 必须出现 59.43.x.x 节点
traceroute -n YOUR_VPS_IP

# 反向解析应指向 chinatelecom.cn（电信用例）
nslookup YOUR_VPS_IP
```

**务必在晚高峰（19:00–23:00）复测丢包率**，合格线 <1%。

> 别在白天测完就下单。白天全绿、晚高峰炸掉的线路非常常见。

### 1.3 机房选择：延迟 vs 风控

| 机房 | 到国内延迟 | AI 风控友好度 |
|------|-----------|--------------|
| 香港 | 30–50ms | ⚠️ 部分 IP 段不友好 |
| 东京/大阪 | 50–90ms | ⚠️ 尚可 |
| **洛杉矶（美西）** | **150–220ms** | ✅ **最友好** |

**如果要"美国原生 IP"，就只有洛杉矶** —— 它是离中国最近的美国机房。

150–220ms 对网页和 API 调用完全够用，只有逐字流式交互（如 Claude Code）会略微有感。

## 四、买前必查清单

### 4.1 向商家确认

- [ ] 出口 IP 是否**长期固定**？
- [ ] 是否**独享**（不是小范围共享）？
- [ ] 是否明确支持 **ChatGPT / Claude / Gemini / OpenAI API**？
- [ ] 被墙或维护时**是否更换 IP**？换 IP 收费吗？
- [ ] 是否支持**退款**？条件是什么？
- [ ] 能否**月付/季付**先试？
- [ ] 月流量多少？超量怎么计费？

> **优先季付而非年付**。多花几美元，换来"如果线路不适合可以及时调整"的选项。

### 4.2 系统选择

**Ubuntu 22.04 或 24.04**。本项目脚本两个版本都支持。

## 五、买到手后立刻验证（部署前）

```bash
# 1. 查 IP 归属、ASN
curl -s https://ipinfo.io/json

# 2. API 连通性（401 = 通的，只是没 key）
curl -sS -o /dev/null -w "%{http_code}\n" https://api.openai.com/v1/models

# 3. 开发依赖可达性
curl -sS -o /dev/null -w "%{http_code}\n" https://github.com
```

**关注点**：

- `org` / `asn` 是否与商家宣传一致（不一致 = 广播 IP，可能影响解锁）
- 是否显示为住宅/ISP（多数会是 Datacenter，**这是正常的**）
- **晚高峰（19:00–23:00）再跑一遍**，看延迟与丢包
