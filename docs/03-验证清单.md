# 验证清单

> 六阶段可勾选清单。每项都有明确判定标准，**不要凭感觉**。

---

## 阶段一：购买前

### 1.1 向商家确认

- [ ] 出口 IP 是否**长期固定**？
- [ ] 是否**独享**？
- [ ] 是否明确支持 **ChatGPT / Claude / Gemini / OpenAI API**？
- [ ] 被墙时**是否更换 IP**？收费吗？
- [ ] 是否支持**退款**？
- [ ] 能否**月付/季付**先试？
- [ ] 月流量多少？超量怎么计费？

### 1.2 线路真伪自检

```bash
# 真 CN2 GIA 必须出现 59.43.x.x 节点
traceroute -n YOUR_VPS_IP
nslookup YOUR_VPS_IP
```

- [ ] 出现对应高端线路的 AS 号（CN2 GIA = 59.43.x.x）
- [ ] **晚高峰（19:00–23:00）复测**，丢包率 <1%
- [ ] 无法提供测试 IP 或结果不符 → 换一家

## 阶段二：部署前

### 2.1 系统与权限

- [ ] 系统是 **Ubuntu 22.04** 或 **24.04**
- [ ] 有 **root** 权限
- [ ] 记下 SSH 端口（若商家改过，需同步改脚本里的 `SSH_PORT`）

### 2.2 安全组放行（最易遗漏）

> 🔴 **商家控制台的"安全组"和系统内 ufw 是两套独立的东西。**
> 脚本只配 ufw。**控制台安全组没放行，照样连不上。**

在**商家控制台**放行：

- [ ] **443/tcp**（VLESS-Reality）
- [ ] **8443/udp**（Hysteria2）
- [ ] SSH 端口/tcp

## 阶段三：部署后

### 3.1 服务状态

```bash
systemctl is-active sing-box        # 期望：active
systemctl is-enabled sing-box       # 期望：enabled
journalctl -u sing-box --no-pager -n 20
```

- [ ] `active`
- [ ] `enabled`（开机自启）
- [ ] 日志无 warning/error

### 3.2 端口监听

```bash
ss -tulnp | grep sing-box
```

- [ ] 看到 **443/tcp** 和 **8443/udp**

### 3.3 配置自校验

```bash
sing-box check -c /etc/sing-box/config.json && echo "配置OK"
```

- [ ] 输出 `配置OK`，退出码 0

> ⚠️ **`check` 通过不等于能启动**。1.14 的两个格式问题（[坑 2](04-踩坑与排查手册.md#2-dns-server-格式在-114-被移除)、[坑 3](04-踩坑与排查手册.md#3-缺少-default_domain_resolver)）
> 都是 `check` 通过但运行时报错。**必须验证 `systemctl is-active`。**

### 3.4 IP 出口质量

```bash
curl -s https://ipinfo.io/json
```

- [ ] `ip` 是 VPS IP
- [ ] `country` 是预期地区
- [ ] `org` 与商家一致（不一致 = 广播 IP）

### 3.5 AI 服务可达性

```bash
curl -sS -o /dev/null -w "openai:%{http_code}\n"   https://api.openai.com/v1/models
curl -sS -o /dev/null -w "anthropic:%{http_code}\n" https://api.anthropic.com/v1/models
curl -sS -o /dev/null -w "google:%{http_code}\n"    https://www.google.com/generate_204
```

- [ ] openai 返回 **401**（= 通，仅缺 key）
- [ ] anthropic 返回 **401/404**
- [ ] google 返回 **204**

> **401/404 是好消息**，证明网络链路通畅。403 + challenge 才需要进一步排查。

### 3.6 下载客户端配置

- [ ] 拿到 `clash-verge.yaml`、`singbox-client.json`、`params.txt`
- [ ] **`params.txt` 含私钥，妥善保管，不要提交到 git**

## 阶段四：本机验证

### 4.1 端口占用检查

```powershell
Get-NetTCPConnection -State Listen -LocalPort 7890 -ErrorAction SilentlyContinue
```

- [ ] 无输出（说明端口空闲）
- [ ] 有输出 → 先关掉占用进程，否则客户端报 `address already in use`

### 4.2 客户端启动与混合入站测试

```powershell
# 先只测混合入站，不开 TUN
curl.exe -x http://127.0.0.1:7890 -s https://ipinfo.io/json
```

- [ ] 返回的 `ip` 是 **VPS IP**

### 4.3 逐协议验证

- [ ] **Hysteria2** 能连通
- [ ] **VLESS-Reality** 能连通
- [ ] 只有一个能通 → 见排查速查表

### 4.4 TUN 模式（最后再开）

- [ ] 打开后浏览器能访问 ChatGPT / Claude
- [ ] **国内网站仍正常**（规则模式下 `GEOIP,CN,DIRECT` 生效）
- [ ] 国内网站变慢 → 检查是否误设为**全局模式**

## 阶段五：WSL 验证

```bash
source ~/.bashrc
curl -s https://ipinfo.io/json | head -3
```

- [ ] WSL 出口显示 **VPS IP**
- [ ] `git clone` 一个 GitHub 仓库成功
- [ ] `npm install`（含境外依赖的项目）成功

> WSL 不通而 Windows 通：90% 是①混合入站绑了 `127.0.0.1`、②没设环境变量、③防火墙 Block 规则。

## 阶段六：上线后

### 6.1 第一周

- [ ] AI 账号未被风控
- [ ] 晚高峰实际体验可接受
- [ ] 无频繁断线
- [ ] 流量消耗在预期内

### 6.2 稳定性验证（重要）

**重启电脑**，然后确认：

```powershell
# 1. 客户端是否自动启动
Get-Process clash-verge | Select-Object Id, StartTime

# 2. TUN 网卡是否就绪
Get-NetAdapter | Where-Object { $_.InterfaceDescription -match 'Meta|Mihomo' }

# 3. 系统代理是否设置
(Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings').ProxyServer

# 4. 出口是否正常
(Invoke-RestMethod https://ipinfo.io/json).ip
```

- [ ] 全部通过 → 配置真正稳定
- [ ] 有失败项 → 见 [坑 9：开机自启未生效](04-踩坑与排查手册.md#9-开机自启未生效)

### 6.3 长期纪律

- [ ] **固定用一个节点**，不每天切换国家/ASN
- [ ] 网页、终端、API **同一出口**
- [ ] **不共用 AI 账号**、不共享凭据
- [ ] API Key 不进代理平台、陌生中转、公开仓库
- [ ] 每月检查：IP 可连性、流量、线路质量

## 附：出问题时的第一反应

| 现象 | 先查什么 |
|------|---------|
| 全部不通，SSH 也连不上 | **IP 被墙**。换 IP（搬瓦工换机房 / DMIT 免费换 IP） |
| SSH 通，代理不通 | 服务状态、端口监听、控制台安全组 |
| 只有 HY2 不通 | UDP 被 QoS → 用 Reality |
| 只有 Reality 不通 | SNI/dest 问题，或 443 被针对 |
| 都通但 AI 站点打不开 | 见 [坑 12：Cloudflare 403](04-踩坑与排查手册.md#12-cloudflare-403-的真相) |
| **速度慢（数秒级延迟）** | 见 [坑 8：DNS 配置](04-踩坑与排查手册.md#8-延迟-4878ms-到-197ms) |
| **国内网站也变慢** | 检查是否误设为全局模式 |
| 重启后失效 | 见 [坑 9](04-踩坑与排查手册.md#9-开机自启未生效) |
