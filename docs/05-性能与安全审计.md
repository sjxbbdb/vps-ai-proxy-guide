# 性能与安全审计

> 上线后的系统性检查，覆盖资源基线、网络健康、分流正确性、流量归因与安全加固。
> 每个检查项附可复现命令与判定基准。

## 审计项概览

| 组 | 检查内容 | 关键判定 |
|----|---------|---------|
| A | 资源占用 | 内存 / CPU / 句柄增长趋势 |
| B | 网络接口健康 | 丢包与错误计数应为 0 |
| C | 连通性与稳定性 | 失败率、延迟、抖动 |
| D | DNS 与分流正确性 | 国内流量不经境外节点 |
| E | 服务端状态 | 负载、流量推算、日志 |
| F | 磁盘与残留 | 异常大文件、旧组件残留 |

---

## 为什么要做审计

部署完成 ≠ 配置正确。实际遇到过的问题：

- 代理延迟 **4878ms**（配置"看起来"完全正确）
- VPS 流量 **~100GB/天**（全局模式导致）
- 开机自启**设置是假的**
- 磁盘被日志吞掉 **10GB**

**这些问题都不会报错，只会静默地影响你。**

## 审计 A：资源占用

### 检查项

```powershell
# 代理栈进程资源
$procs = Get-Process | Where-Object { $_.ProcessName -match 'clash|verge|mihomo' }
$procs | Select-Object ProcessName, Id,
    @{n='内存MB';e={[math]::Round($_.WorkingSet64/1MB,1)}},
    @{n='CPU秒';e={[math]::Round($_.CPU,1)}},
    @{n='线程';e={$_.Threads.Count}} | Format-Table -AutoSize

$totalMem = ($procs | Measure-Object -Property WorkingSet64 -Sum).Sum/1MB
"总计: $([math]::Round($totalMem,1)) MB"
```

```powershell
# CPU 采样（5 秒内的实际占用，比累计值更有意义）
$p = Get-Process | Where-Object { $_.ProcessName -match 'mihomo|clash-verge' }
$before = @{}; foreach($x in $p){ $before[$x.Id] = $x.CPU }
Start-Sleep -Seconds 5
$p2 = Get-Process | Where-Object { $_.ProcessName -match 'mihomo|clash-verge' }
foreach($x in $p2){
    $used = $x.CPU - $before[$x.Id]
    $pct = [math]::Round($used/5*100/$env:NUMBER_OF_PROCESSORS, 2)
    "{0,-22} 5秒CPU: {1}s ≈ {2}%" -f $x.ProcessName, [math]::Round($used,2), $pct
}
```

### 判定基准

| 指标 | 正常范围 | 实测参考 |
|------|---------|---------|
| 代理栈总内存 | 100–250 MB | **137 MB** |
| 代理栈 CPU | <1% | **0.02%** |
| App 内存 | 40–80 MB | 51 MB |
| 内核内存 | 60–120 MB | 79 MB |
| 服务内存 | 5–15 MB | 7 MB |

### ⚠️ 异常信号

| 现象 | 可能原因 |
|------|---------|
| 内核内存持续增长（数天到 GB） | 连接数泄漏 / 规则集缓存问题 |
| CPU 持续 >5% | TUN 流量大 / 日志级别过低 / 规则过多 |
| 句柄数持续增长 | 连接未正确关闭 |

## 审计 B：网络接口健康

```powershell
Get-NetAdapterStatistics -Name 'Mihomo' | Format-List
Get-NetAdapterStatistics -Name '以太网'  | Format-List
```

### 判定基准

**以下全部应为 0：**

```
ReceivedDiscardedPackets : 0
OutboundDiscardedPackets : 0
ReceivedPacketErrors     : 0
OutboundPacketErrors     : 0
```

**任何非零值都说明有问题**（丢包/错误），需要排查 TUN 配置。

## 审计 C：连通性与稳定性

### C1. 连续请求测试（测丢包与抖动）

```powershell
$t = @(); $fail = 0
1..30 | ForEach-Object {
    try {
        $sw = [Diagnostics.Stopwatch]::StartNew()
        Invoke-WebRequest 'https://www.gstatic.com/generate_204' -TimeoutSec 15 | Out-Null
        $sw.Stop(); $t += $sw.Elapsed.TotalMilliseconds
    } catch { $fail++ }
    Start-Sleep -Milliseconds 120
}
$s = $t | Measure-Object -Average -Minimum -Maximum
"成功 $($t.Count)/30  失败 $fail"
"最小 {0}ms / 平均 {1}ms / 最大 {2}ms" -f [math]::Round($s.Minimum),[math]::Round($s.Average),[math]::Round($s.Maximum)
$jit = [math]::Round((($t | ForEach-Object { [math]::Abs($_ - $s.Average) }) | Measure-Object -Average).Average, 1)
"抖动 $jit ms"
```

### 判定基准

| 指标 | 优秀 | 可接受 | 需排查 |
|------|------|--------|--------|
| 失败率 | 0% | <2% | >2% |
| 平均延迟（美西） | <200ms | 200–280ms | >300ms |
| 抖动 | <20ms | 20–50ms | >50ms |
| 最大延迟 | <1.5× 平均 | <2× 平均 | >2× 平均 |

**实测参考**：失败率 0%，平均 197ms，抖动 15.5ms

### C2. 多平台端点测试

```powershell
$eps = @(
    'https://www.google.com/generate_204','https://api.openai.com/v1/models',
    'https://api.anthropic.com/v1/models','https://github.com','https://api.github.com',
    'https://registry.npmjs.org','https://pypi.org','https://huggingface.co',
    'https://www.youtube.com','https://x.com','https://stackoverflow.com'
)
foreach ($u in $eps) {
    try {
        $r = Invoke-WebRequest $u -TimeoutSec 20 -SkipHttpErrorCheck
        "  OK  {0,-42} HTTP {1}" -f ($u -replace 'https://'), $r.StatusCode
    } catch { "  FAIL {0,-42}" -f ($u -replace 'https://') }
}
```

> **注意**：`stackoverflow.com`、`dash.cloudflare.com` 等对自动化请求返回 403 是**正常的反爬**，
> 不代表代理有问题。用浏览器验证。

## 审计 D：DNS 与分流正确性

### D1. 确认是否 fake-ip 模式

```powershell
foreach ($h in @('www.google.com','www.baidu.com','github.com')) {
    $ip = (Resolve-DnsName $h -Type A | Where-Object IPAddress | Select-Object -First 1).IPAddress
    $type = if ($ip -match '^198\.18\.') { 'fake-ip' } else { '真实IP' }
    "  {0,-22} -> {1,-16} {2}" -f $h, $ip, $type
}
```

**预期**：全部为 `198.18.x.x`（fake-ip 段）

### D2. 确认分流规则生效（关键）

```powershell
# 生成国内流量
1..10 | ForEach-Object {
    Invoke-WebRequest 'https://www.baidu.com' -TimeoutSec 15 | Out-Null
    Invoke-WebRequest 'https://www.taobao.com' -TimeoutSec 15 | Out-Null
}
```

```bash
# 同时在 VPS 上读网卡计数（前后各读一次）
cat /sys/class/net/ens3/statistics/rx_bytes /sys/class/net/ens3/statistics/tx_bytes
```

**判定**：国内流量导致的 VPS 增量应 **<2 MB**

**实测参考**：20 次国内请求 → 增量仅 **0.121 MB** ✅

> 如果增量很大（几十 MB），说明**误设为全局模式**，见 [故障 13](04-故障排查手册.md#13-全局模式导致流量浪费)。

### D3. 国内站点延迟

```powershell
foreach ($u in @('https://www.baidu.com','https://www.taobao.com','https://www.qq.com')) {
    $sw = [Diagnostics.Stopwatch]::StartNew()
    Invoke-WebRequest $u -TimeoutSec 20 | Out-Null
    $sw.Stop()
    "  {0,-24} {1}ms" -f ($u -replace 'https://'), [math]::Round($sw.Elapsed.TotalMilliseconds)
}
```

**判定基准**：

| 模式 | 国内站点延迟 |
|------|-------------|
| 规则模式（正确） | **150–250 ms** |
| 全局模式（错误） | 1300–2000 ms |

## 审计 E：VPS 服务端

```bash
# 服务健康
systemctl is-active sing-box && systemctl is-enabled sing-box
uptime -p && cat /proc/loadavg

# 资源
free -m
df -h /
ps -o rss=,pcpu= -p $(pgrep -x sing-box)    # 内核进程占用

# 流量
cat /proc/net/dev | awk 'NR>2 && $1 !~ /lo:/ {gsub(/:/,"",$1); printf "%-12s RX %.1f MB / TX %.1f MB\n", $1, $2/1048576, $10/1048576}'

# 端口
ss -tulnp | grep -E 'sing-box|:443|:8443'

# 安全
systemctl is-active fail2ban
ufw status | head -1

# 错误日志
journalctl -u sing-box --no-pager -p warning -n 20
```

### 判定基准

| 指标 | 正常范围 | 实测参考 |
|------|---------|---------|
| 服务状态 | active + enabled | ✅ |
| 系统负载 | <0.5 | **0.05** |
| 内存占用 | <500 MB | 359 / 2932 MB |
| 磁盘占用 | <20% | 3.0 / 49 GB (7%) |
| sing-box 内存 | 50–150 MB | **83.9 MB** |
| sing-box CPU | <5% | 1.2% |
| 警告日志 | 0 条 | **0 条** |

### ⚠️ 流量异常判定

```
推算日消耗 = (当前累计流量 / 已运行小时数) × 24
```

| 推算日消耗 | 2TB 配额可用 | 判定 |
|-----------|-------------|------|
| <10 GB/天 | >200 天 | ✅ 正常 |
| 10–30 GB/天 | 60–200 天 | ⚠️ 关注 |
| **>50 GB/天** | **<40 天** | 🔴 **排查** |

我们实测遇到的 **~100GB/天** 就是红线，根因是全局模式。

## 审计 F：磁盘与残留

### F1. 找异常大文件

```powershell
# 程序的日志/数据库目录
Get-ChildItem "$env:USERPROFILE\.codex" -File |
    Where-Object { $_.Length -gt 50MB } |
    Sort-Object Length -Descending |
    Select-Object Name, @{n='MB';e={[math]::Round($_.Length/1MB,1)}}

# 各盘剩余空间
Get-PSDrive -PSProvider FileSystem |
    Select-Object Name,
        @{n='已用GB';e={[math]::Round($_.Used/1GB,1)}},
        @{n='可用GB';e={[math]::Round($_.Free/1GB,1)}}
```

### 判定基准

- 单盘使用率 **>85%** 需要清理
- 日志文件 **>500MB** 需要关注

### F2. 检查旧软件残留

```powershell
# 旧代理软件的进程
Get-Process | Where-Object { $_.ProcessName -match 'ikuuu|v2ray|nekoray|shadowsocks|xray' }

# 旧服务是否还在自启
Get-Service | Where-Object { $_.Name -match 'ikuuu|v2ray|xray' } |
    Select-Object Name, Status, StartType

# 网络适配器残留
Get-NetAdapter -IncludeHidden | Where-Object { $_.InterfaceDescription -match '旧软件名' }
```

### F3. 残留服务是否影响网络（判定方法）

**重点：一个"正在运行"的服务不一定影响网络。** 用这几项判断：

```powershell
$targetPid = (Get-Process -Name '服务名').Id

# ① 是否监听端口
Get-NetTCPConnection -State Listen -OwningProcess $targetPid
Get-NetUDPEndpoint -OwningProcess $targetPid

# ② 是否有网卡关联
Get-NetAdapter -IncludeHidden | Where-Object { $_.InterfaceDescription -match '旧软件' }

# ③ 是否污染路由表
Get-NetRoute -DestinationPrefix '0.0.0.0/0'

# ④ 是否改了 DNS
Get-DnsClientServerAddress -AddressFamily IPv4
```

**实测案例**：某残留服务"正在运行"但——

```
TCP 端口监听     : 无
UDP 端口监听     : 无
网络适配器       : 无
路由表污染       : 无
DNS 篡改         : 无
资源占用         : 5.8 MB，CPU 累计 0 秒
```

**结论：不影响网络。** 只是一个空转的守护进程。

## 安全加固建议

### 必做

- [ ] **改 root 密码**（如果曾以任何形式暴露过）
  ```bash
  passwd
  ```
- [ ] **检查 SSH 是否禁用了密码登录**（配置密钥后）
  ```bash
  grep -rEi 'passwordauth|permitroot' /etc/ssh/sshd_config /etc/ssh/sshd_config.d/
  ```
- [ ] **确认 ufw 只放行必要端口**
  ```bash
  ufw status verbose
  ```
- [ ] **确认 fail2ban 运行中**
  ```bash
  fail2ban-client status sshd
  ```

### 建议

- [ ] SSH 改用密钥登录 + 禁用密码
- [ ] 改 SSH 默认端口（减少扫描）
- [ ] 定期检查 `/var/log/auth.log` 的异常登录尝试
- [ ] 敏感配置文件（含 key/token）不要进 git

### 客户端侧

- [ ] 环境变量里不要写明文 API Key
- [ ] 中转站/代理服务的 Token 定期轮换
- [ ] 检查是否有明文 token 存在于配置文件

```powershell
# 搜索本地配置里的明文 token
Get-ChildItem "$env:USERPROFILE\.claude","$env:USERPROFILE\.codex" -Recurse -File -EA SilentlyContinue |
    Where-Object { $_.Length -lt 1MB } |
    Select-String -Pattern 'sk-[a-zA-Z0-9]{20,}' -List |
    Select-Object Path
```
